# V44 — Firestorm Egress

V44 extends the Desert approach and makes the successful strike end in a sustained destruction event instead of a single flash.

## Changes

- Desert insertion now begins roughly six miles from the Launch Complex.
- Terrain and scenery are recentered around the more distant starting point.
- The first interceptor is re-staged relative to the new insertion point; the V43 aggressive northbound intercept behavior remains intact.
- Final launch-vehicle destruction now ignites multiple persistent fire pockets across the complex.
- Fuel / ordnance secondary explosions cook off during the escape.
- Firelight and smoke remain visible while EW-01 egresses, so the destroyed target stays behind you as geographic memory.
- Mission Control changes to TARGET DESTROYED / EGRESS NORTH — HIGH PASS / GO.
- Desert-to-Alpine transition now prefers a physical northbound escape beyond the target; a 30-second fallback prevents a stuck run.
- No changes to flight model, camera, turbo audio, cannon, missile handling, V42 terrain-masking logic, or V43 interceptor behavior.

Build with: `node scripts/build-v44.mjs`.
